In this mini project, my code uses HTML, CSS, and JavaScript with Canvas to reconstruct Teto using text, the image was transformed into a matrix of RGB colors, where each [R,G,B] represents the color of a point in her image—for example, [255,255,255] is white... The JavaScript takes these colors and places letters from "TETO" at each position in the grid, creating the image when we look at it from a distance... Then, the offset makes the text move continuously, creating that animated effect :3
